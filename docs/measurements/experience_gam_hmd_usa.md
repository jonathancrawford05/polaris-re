## Caveats

- Pearson dispersion φ = 21.84, so the quasi-Poisson covariance scaling was applied: every band below is 4.67x wider than a plain-Poisson fit would have reported. The point estimates are unchanged — scaling touches the covariance only. A φ this far above 1 means unmodelled heterogeneity, which is expected on real grouped data and is why the scaling is not optional here.
- The base offset is estimated from these same cells, so `overall_ae` is ~1 by construction and is not an independent check on the level. The fitted improvement is unaffected: it is a calendar contrast, and every calendar-invariant term — the offset included — cancels in the difference.
